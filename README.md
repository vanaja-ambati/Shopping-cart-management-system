# Shopping Cart Management System

## Overview

This is a simple Shopping Cart Management System developed using Python and Object-Oriented Programming (OOP) concepts. The application allows users to add items to a cart, remove items, view cart contents, and calculate the final bill after applying a flat discount.

## Features

* Add items to the shopping cart
* Remove items from the shopping cart
* View all items in the cart
* Calculate the total bill
* Apply a flat discount on eligible purchases
* Validate minimum cart value before checkout

## Technologies Used

* Python
* Object-Oriented Programming (OOP)

## OOP Concepts Implemented

* Classes and Objects
* Constructors (`__init__`)
* Class Attributes
* Instance Attributes
* Encapsulation

## Project Structure

* `Cart` class manages cart operations.
* Class attributes store discount and minimum bill requirements.
* Instance attributes store cart items and prices.
* Methods handle adding, removing, displaying items, and bill calculation.

## Sample Output

* Add items to cart
* View cart contents
* Remove items
* Calculate final payable amount after discount
